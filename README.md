### 🏨 Hotel Essentia — Gestão de Reservas

Aplicação web desenvolvida para gerenciamento de reservas de hotel, integrando um site institucional com um painel administrativo.

O projeto conta com:

- Catálogo de quartos
- Formulário de reservas
- Validação no cliente
- Autenticação e sessões
- Dashboard administrativo
- CRUD de reservas
- CRUD de quartos
- CRUD de usuários
- Integração com MySQL utilizando PDO
- Arquitetura MVC

**Tecnologias do projeto:** PHP 8, HTML, CSS, JavaScript, MySQL e PDO.
